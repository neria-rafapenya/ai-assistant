# Tarot card assets

Add the local Rider-Waite-Smith card images to this directory. The Tarot page
expects PNG files with these names:

```text
00_fool.png
01_magician.png
02_high_priestess.png
03_empress.png
04_emperor.png
05_hierophant.png
06_lovers.png
07_chariot.png
08_strength.png
09_hermit.png
10_wheel_of_fortune.png
11_justice.png
12_hanged_man.png
13_death.png
14_temperance.png
15_devil.png
16_tower.png
17_star.png
18_moon.png
19_sun.png
20_judgement.png
21_world.png
```

The current prototype uses the 22 Major Arcana. If an image is missing, the
interface shows its expected filename instead of a broken image. Keep a copy
of the source and license/attribution information for the selected deck in
this directory before using the assets publicly.
